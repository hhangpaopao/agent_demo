# 竞品分析框架与方法论（问数系统分析竞品时遵循）
整理日期：2026-11-25
资料来源：公开电商运营竞品分析方法论（选对标/拆 Listing/评论分析/输出动作四步法）、三个皮匠报告水杯市场分析、共研网保温杯行业报告、聚慧网品牌价格分析。
## 一、先定目标：分析要回答什么
竞品分析前先明确目标是"追销售额份额"还是"追利润"——这直接决定数据侧重点与结论方向。本知识库支持的分析目标：
- **市场格局**：品类内有哪些玩家、份额如何（数据库销量/GMV + 网络公开份额数据）
- **价格带定位**：高端/中端/大众的价格分层与受众（高端/中端产品线档案）
- **差评痛点**：用户对某类产品的不满（评论数据 + 网络评论）
- **运营动作**：竞品什么时候降价/促销、评论怎么增长（网络搜索 + 数据库时间趋势）
## 三、核心盯这些数据（六维）
**红线**：拿不到的数据（广告流量、Keepa 价格曲线、评分重置历史）不要编造。宁可回答"该维度暂无数据，建议补充 XX 数据源"，也不要生成看似合理的假数字。
## 四、四步分析法（回答竞品问题时按此结构）
1. **选目标、搭框架**：先说清这次分析回答什么问题（份额/价格/痛点/动作），再选直接+间接+标杆对标
2. **拆产品、看历史**：拆产品线/价格/材质/受众；有历史数据时看价格与评论的时间趋势，反推运营节奏（何时降价、何时促销）
3. **评论分析**：从评论归纳结论，尽量能追溯到用户原话；用 AI 做聚类而非逐条翻
4. **输出具体动作**：不要只写"分析了竞品什么"，必须写"接下来我干什么"——这是硬要求。每份竞品分析结尾必须给出 2-4 条可执行建议（如"中端段应强化 316L 内胆卖点""高端款需在¥100-200 重叠带设防"）

## 二、指标口径（重要，避免算错）
- **GMV（成交总额）** = SUM(fact_order.order_amount) ——按商品/品牌/地区/时间聚合均可得
- **AOV（平均订单金额）** = SUM(order_amount) / COUNT(order_id) 或 AVG(order_amount) ——**应关联 order_amount，不是 order_quantity**
  - ⚠️ 注意：当前元数据配置 meta_config.yml 里 AOV 的 relevant_columns 误写为 order_quantity（销量），这是原配置的笔误。回答 AOV 问题时以本文件口径为准，用 order_amount 计算。
- **销量** = SUM(order_quantity)；**订单数** = COUNT(order_id)；两者不同，不要混用
- **客单价（每件均价）** = SUM(order_amount) / SUM(order_quantity)
